
# React Profile Card

A personal profile card built with React as my first React project. It displays profile information, a short bio, skills, and social links in a simple, responsive-style card layout.

## ✨ Features

- Profile image with a circular design
- Personal information and bio section
- Skills displayed as badges
- GitHub and LinkedIn social links
- Gradient header and custom CSS styling
- Separate React components for a structured layout

## 🛠️ Tech Stack

- React.js
- JavaScript
- CSS
- HTML

##  Getting Started

### 1. Clone the repository
### 2. Navigate to the project folder
### 3. Install dependencies
### 4. Start the development server
The application will run at `http://localhost:3000`.

- Building and organizing React components
- Importing images into React
- Styling components using CSS
- Working with gradients, borders, and layouts
- Adding external social links
- Debugging errors during development
